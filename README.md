# Academic Learning Platform 📚

A Duolingo-like learning platform designed for students (Nursery to 12th grade) to learn academic subjects with gamification, personalized learning paths, and behavioral analytics.

## 🎯 Features

### 1. **Class & Subject Management**
- Classes: Nursery to 12th Grade
- Dynamic subject mapping per class
- Subject-specific content and quizzes

### 2. **Learning Content**
- Quizzes (Multiple Choice, Fill-in-the-blank, etc.)
- Challenges (Weekly/Monthly competitions)
- Streaks (Daily practice motivation)
- Progress Tracking

### 3. **Gamification**
- Points & XP System
- Leaderboards
- Achievement Badges
- Streak Counter
- Daily Challenges

### 4. **Behavioral Analytics & Personalization**
- Learning Style Detection (Visual, Audio, Written, Kinesthetic)
- Performance Analytics
- Personalized Study Recommendations
- Learning Pace Adaptation

## Tech Stack
- **Frontend**: React.js / React Native
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## Installation
```bash
git clone https://github.com/abhinav082006/academic-learning-app.git
cd academic-learning-app

# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm start
```
