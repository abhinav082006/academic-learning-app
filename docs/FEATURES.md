# Features Documentation

## 1. Class & Subject Management
- Students select class during onboarding
- Subjects dynamically loaded per class
- Topics within subjects for structured learning

## 2. Quiz System
- Multiple question types (MCQ, Fill-in-the-blank, T/F, Short Answer)
- Three quiz types: Practice, Challenge, Assessment
- Automatic grading and feedback

## 3. Gamification
- **XP System**: Points earned from quiz completion
- **Streaks**: Bonus multipliers for consistent practice
- **Badges**: Achievement system for milestones
- **Leaderboards**: Global, class-level, and subject-specific
- **Levels**: Progressive leveling with XP thresholds

## 4. Learning Style Detection
- Visual, Auditory, Reading/Writing, Kinesthetic
- Automatic detection based on performance patterns
- Personalized content recommendations

## 5. Analytics & Personalization
- Performance tracking per subject
- Weak area identification
- Smart recommendations for improvement
- Progress reports and insights

## 6. Challenges & Competitions
- Daily challenges
- Weekly theme-based competitions
- Monthly class competitions
- Leaderboard rankings

## 7. Study Habits
- Track daily study time
- Consistency scoring
- Motivational notifications
- Goal setting and tracking
